# MAPS 11 - Management of Air Pollution Sector 11 🌍💨

ระบบบริหารจัดการมลพิษทางอากาศ เขตพื้นที่ 11 (MAPS 11) พัฒนาขึ้นเพื่อเป็นเครื่องมือเชิงพื้นที่ (Spatial Tool) สำหรับเฝ้าระวัง ติดตาม และแจ้งเตือนภัยด้านมลพิษทางอากาศ โดยเน้นไปที่การจัดการจุดความร้อน (Hotspots) และประเมินความเสี่ยงไฟไหม้สถานที่กำจัดขยะมูลฝอยในพื้นที่รับผิดชอบ 4 จังหวัด ได้แก่ นครราชสีมา ชัยภูมิ บุรีรัมย์ และสุรินทร์

## 🌟 คุณสมบัติเด่น (Features)

*   **🛰️ ติดตามจุดความร้อนเรียลไทม์:** ดึงข้อมูลจุดความร้อนจากดาวเทียม NASA (Suomi-NPP) พร้อมแสดงระดับความเชื่อมั่น (Confidence)
*   **⏱️ ตัวกรองช่วงเวลา:** เลือกดูข้อมูลจุดความร้อนย้อนหลัง 24 ชั่วโมง หรือแยกดูเฉพาะรอบเช้า (00:00 - 11:59 น.) และรอบบ่าย (12:00 - 23:59 น.)
*   **🗑️ ฐานข้อมูลบ่อขยะ:** แสดงพิกัดสถานที่กำจัดขยะมูลฝอย พร้อมแยกสีตามขนาดพื้นที่ (ไร่) และแจ้งเตือนบ่อขยะที่มีความเสี่ยง (ขยะล้นพื้นที่)
*   **🚨 ระบบแจ้งเตือนไฟไหม้บ่อขยะอัตโนมัติ:** วิเคราะห์ระยะห่างระหว่างจุดความร้อนและบ่อขยะ หากพบจุดความร้อนในรัศมี 500 เมตร ระบบจะแจ้งเตือนความเสี่ยงทันที
*   **📍 ระบบจัดการจุดเกิดเหตุด่วน:** 
    *   ปักหมุดจุดเกิดเหตุบนแผนที่
    *   ดึงข้อมูลสภาพอากาศและทิศทางลมแบบเรียลไทม์ ณ จุดเกิดเหตุ
    *   จำลองทิศทางควันไฟ (Plume) และวิเคราะห์ชุมชนท้ายลมที่อาจได้รับผลกระทบในระยะ 2-5 กิโลเมตร
*   **📥 ระบบส่งออกข้อมูล:** ดาวน์โหลดข้อมูลจุดความร้อนเป็นไฟล์ Excel (ปกป้องการเข้าถึงด้วยระบบรหัสผ่าน)
*   **🗺️ แผนที่พื้นฐานหลากหลาย:** เลือกสลับแผนที่พื้นฐานได้ทั้ง OpenStreetMap และภาพถ่ายดาวเทียม (Esri และ Google)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

ระบบนี้พัฒนาในรูปแบบ **Client-side Web Application** โดยใช้เทคโนโลยีดังต่อไปนี้

*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Mapping Library:** [Leaflet.js](https://leafletjs.com/) (แผนที่เชิงโต้ตอบ) และ Leaflet.markercluster (จัดกลุ่มจุดพิกัด)
*   **Spatial Analysis:** [Turf.js](https://turfjs.org/) (วิเคราะห์ข้อมูลเชิงพื้นที่ เช่น การสร้างรัศมี ระยะทาง และจุดตัด)
*   **Data Export:** [SheetJS](https://sheetjs.com/) (สร้างไฟล์ Excel)
*   **Security:** CryptoJS (เข้ารหัส Hash สำหรับป้องกันการดาวน์โหลดข้อมูล)
*   **External APIs:**
    *   **Longdo Map API:** แปลงพิกัด (Lat/Lon) เป็นชื่อตำบล อำเภอ จังหวัด (Reverse Geocoding)
    *   **Open-Meteo API:** ดึงข้อมูลความเร็วและทิศทางลมปัจจุบัน
    *   **Google Apps Script (GAS):** ทำหน้าที่เป็น Backend API ดึงข้อมูลจุดความร้อน NASA FIRMS และฐานข้อมูลบ่อขยะจาก Google Sheets

## 🔐 ข้อมูลสำหรับผู้พัฒนา (Developer Notes)

*   **API Keys:** ในระบบมีการเรียกใช้ `longdoApiKey` ซึ่งถูกฝังไว้ในโค้ด หากนำไปพัฒนาต่อควรเปลี่ยนเป็น API Key ของหน่วยงานท่านเอง
*   **Backend Data:** การดึงข้อมูลจุดความร้อนและบ่อขยะ ดำเนินการผ่าน URL ของ Google Apps Script (`gasWebappUrl` และ `wasteGasUrl`) 
*   **Password Hash:** รหัสผ่านสำหรับดาวน์โหลดไฟล์ Excel ถูกเข้ารหัสด้วย SHA3 (512-bit) หากต้องการเปลี่ยนรหัสผ่าน ต้องสร้างค่า Hash ใหม่แล้วนำมาแทนที่ในตัวแปร `TARGET_HASH`
